# Dudes Editor

Локальный редактор пиксельных дудесов для [Twir](https://github.com/twirapp/dudes). Рисует 32×32 покадрово по слоям и экспортирует пакет, совместимый с текущим движком оверлея.

## Запуск

```bash
pnpm install
pnpm --filter @dudes/editor dev
```

Открыть `http://localhost:5173`.

Сборка статики:

```bash
pnpm --filter @dudes/editor build
# результат в apps/editor/dist
```

## Как рисовать

- Выбери болванку (`Dude`, `Cat`, `Devil`) или пустой холст.
- Слои: `Body`, `Eyes`, `Mouth`, `Hat`, `Cosmetics`. Рисование идёт только в активный слой.
- Кадры идут в фиксированном порядке движка:
  `idle 0–2` (300 мс), `jump 3`, `fall 4`, `land 5`, `run 6–8` (100 мс).
- «Save frame → next» копирует текущий кадр в следующий и переключает на него.
- Инструменты: `B` кисть, `E` ластик, `F` заливка, `I` пипетка. `Ctrl/Cmd+Z` — undo, `Ctrl/Cmd+Shift+Z` — redo.
- «Show previous frame» включает призрак предыдущего кадра.
- Проекты автоматически сохраняются в IndexedDB браузера.

## Важно для совместимости

- **Тело должно быть в градациях серого** (`R=G=B`): бот перекрашивает его через `tint`, цветное тело даст грязь. Редактор показывает ошибку и блокирует экспорт.
- Остальные слои могут быть цветными.
- Используй полностью непрозрачные или полностью прозрачные пиксели: полупрозрачность даёт предупреждение.

## Экспорт

`Export` скачивает zip:

```
body.png        # 288×32, 9 кадров по 32×32
eyes.png
mouth.png
hat.png
cosmetics.png
dude.json       # имя, карта слоёв, цвета
preview.png     # контактный лист 3×3
```

Тот же пакет можно импортировать обратно через `Import`.

## Болванки

Шаблоны собираются из спрайтов плейграунда:

```bash
pnpm --filter @dudes/editor templates
```

Скрипт пишет `public/templates/<id>.zip` и `<id>.png` для `dude`, `cat`, `devil`.
