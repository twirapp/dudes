# Редактор спрайтов

1. Реализовать слои на спрайте ввиде таблицы [слой/анимация] (body, eye, hat, mouth, cosmetic)
2. Реализовать undo, redo (история изменений)
3. Исправить баг при рисовании (прерывается при резком движении мыши и за границей канваса)
4. Релизовать шорткаты для рисования (draw, erase, fill, clipboard, pixel selection)
5. Реализовать историю цветов, палитру цветов, смена цвет 1 и цвет 2 (рисование через ЛКМ и ПКМ)
6. Добавить функцию выделения объектов на канвасе с возможность ресайзинга и перемещения (SHIFT - выделение, CTRL - перемещение)
7. Копирование выделенных пикселей на канвасе, перенос буфер обмена на другие канвасы
8. Просчет коллайдера для спрайта
